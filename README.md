# TheLoop-Voltaje

# Github repository for The Loop (Voltaje)
# The Loop (Voltaje) is an iteration of The Loop, modified for the Voltaje Festival
# The Loop (Voltaje) will connect The Loop, Chicago and Voltaje, Colombia together via Live news

# Using live discourse from inside the Loop, Chicago, Voltaje festival will be updated with headlines relevant to the live discourse.
# Every 6 hours, the updated list of headlines will arrive in BOG from ORD.

# The presented headlines is not pre-determined and will vary from day to day
# The Loop (Voltaje) does not support a particular political movement or action, and is only a representation of on going discourse of the public
